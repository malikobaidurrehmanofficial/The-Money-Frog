Prompt 03
5 Script Architectures
Rotate these to prevent pattern detection. Never use the same architecture twice in a row. Each has a completely different flow, pacing, and opening style.
Rotation rule: Use the rotation schedule at the bottom. Never use the same architecture back-to-back. Add your chosen architecture to the [Architecture] field in the Master Prompt.
Architecture 01
"The Myth Buster"
Best for: Contrarian Pillar
  • Open stating the myth as FACT — no hint you'll destroy it
  • Spend 3 full minutes validating why people believe it
  • Hard pivot: "Except here's the problem with that"
  • Math destruction of the myth
  • Rebuild: what actually works instead
  • Close with the corrected belief as a new mental model
Architecture 02
"The Story + Math"
Best for: Age Hook Pillar
  • Open with 60-sec fictional but realistic story ("Meet Sarah...")
  • Use Sarah's situation to set up the entire problem
  • Run all math using her specific numbers
  • Midpoint: introduce a second character with opposite choices
  • Reveal what happened to both at age 65
  • Close: "Which path are YOU currently on?"
Architecture 03
"The Live Calculation"
Best for: Real Math Pillar
  • Open mid-calculation: "I just ran the numbers and..."
  • Walk through math in real time as if discovering it
  • Stop at shocking result: "Wait — look at this number"
  • Rerun with different variables to show range
  • Build a comparison table live
  • Close: "So which scenario are YOU in right now?"
Architecture 04
"The List With a Twist"
Best for: List Pillar
  • Open by revealing the LAST item first — tease #1 immediately
  • Run through items 10 down to 2
  • Each item: name → cost in dollars → fix in one sentence
  • Build tension toward #1 throughout the video
  • #1 reveal is the contrarian twist nobody expected
  • Close: "How many of these are you guilty of?"
Architecture 05
"The Debate Format"
Best for: Real Math / Comparison Pillar
  • Open: "I'm going to argue both sides and let the math decide"
  • Spend 5 minutes making strongest case for Option A
  • Spend 5 minutes making strongest case for Option B
  • The math showdown: run numbers for both
  • Declare a winner — but with specific conditions
  • Close: "Which side wins for YOUR situation?"
