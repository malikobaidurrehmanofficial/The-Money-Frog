Core Thumbnail Rules — Never Break These
APPLY TO EVERY SINGLE THUMBNAIL
CORE THUMBNAIL RULES — The Money Frog Channel

COMPOSITION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[1] Daddu (the frog character) occupies 35–50% of the thumbnail
[2] Daddu must ALWAYS be reacting to something — never neutral pose
[3] One dominant text element only — max 5 words, largest element on screen
[4] One supporting text element — max 3 words, much smaller
[5] Never more than 3 visual elements total: Daddu + text + background element
[6] The eye travels: Text → Daddu's expression → supporting element

TEXT RULES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[7] Main text must be readable at 120px width (mobile size)
[8] Never use more than 2 fonts on one thumbnail
[9] Text must have contrast ratio of at least 4.5:1 against background
[10] Main text uses thick bold condensed font — never thin fonts
[11] Key word or number gets a different color from the rest of the text
[12] Never use all lowercase — looks unprofessional at small size

COLOR RULES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[13] Each thumbnail uses ONE dominant background color + ONE accent
[14] Never use more than 3 colors total including text
[15] Rotate color palette every video — never same palette back to back
[16] High contrast always wins — dark bg + bright text OR light bg + dark text
[17] Daddu's green naturally becomes a color element — design around it

DADDU RULES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[18] Daddu's expression must match the video's emotional hook
[19] Daddu's eyes must be visible and large — this is his most recognizable feature
[20] Never shrink Daddu below 30% of frame — he IS the brand
[21] Daddu should be pointing at, reacting to, or interacting with the text
[22] Never put Daddu in the center — always left or right, slightly off-frame at edges

WHAT TO NEVER DO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✕ Never use the same layout style twice in a row
✕ Never use same background color as previous video
✕ Never use a thumbnail without Daddu visible
✕ Never use light gray backgrounds — too weak on YouTube grid
✕ Never put important text in corners — YouTube UI covers corners
✕ Never use stock photo faces — Daddu replaces the human face element
✕ Never add more than one emoji or graphic element besides Daddu
Tab 02
Daddu Character Rules
Every thumbnail you generate needs Daddu positioned and posed correctly. These rules tell the AI image tool exactly how to use him. Paste these into every prompt you send.
😱
Shocked / Surprised Pose
Use for: Contrarian videos, shocking stats, "you've been doing this wrong" topics.

Direction: Eyes wide open, mouth slightly open, one hand raised near face, leaning slightly back, beanie slightly tilted
Never: Closed eyes, calm expression, looking away from camera
🤫
Secretive / Insider Pose
Use for: "Banks don't want you to know," loophole videos, hidden information topics.

Direction: One finger on lips, eyes looking sideways or directly at viewer, slight smirk, leaning forward conspiratorially
Never: Open mouth, surprised look, pointing away
😤
Frustrated / Warning Pose
Use for: Mistake videos, "stop doing this," warning topics, debt and financial danger content.

Direction: Arms crossed or one hand pointing forward at viewer, eyebrows furrowed, serious expression, direct eye contact
Never: Smiling, neutral, looking away
💡
Excited / Discovery Pose
Use for: "Real Math" reveals, empowerment content, positive financial tips, savings discoveries.

Direction: Both hands up or one pointing up, big wide eyes, enthusiastic open expression, slight forward lean
Never: Arms down, flat expression, looking sideways
🤔
Thinking / Calculating Pose
Use for: Comparison videos, "which is better" content, math-heavy real calculation topics.

Direction: One hand on chin, eyes slightly narrowed and looking up-left as if thinking, head tilted slightly, other hand with finger raised
Never: Blank stare, arms at sides, big open expression
😎
Confident / Knowing Pose
Use for: Age hook videos, "do this immediately," actionable step-by-step content, empowerment closes.

Direction: Arms crossed confidently, slight smirk or small smile, direct eye contact, slightly leaning back, beanie perfectly placed
Never: Surprised look, hands in air, frantic energy

8 Thumbnail Visual Styles
Rotate through these 8 styles on a fixed schedule. Each has a completely different visual identity — background treatment, text layout, color mood, and Daddu placement. Never use the same style twice in a row.
💥
STYLE A
The Red Alarm
Dark/black background. Dominant red accent. Daddu on LEFT with shocked expression. Bold white main text on right. Red highlight on key number or word.
→ Best for: Mistake videos, warnings, shocking stats
📊
STYLE B
The Navy Math
Deep navy/dark blue background. Gold/yellow accents. Daddu on RIGHT in thinking pose. Main text LEFT side. Subtle chart or number graphic behind text.
→ Best for: Real Math comparisons, data-driven videos
💰
STYLE C
The Green Machine
Very dark green background. Bright neon green accents. Daddu LARGE on right (50% frame). Short punchy text left. Money/wealth visual element behind Daddu.
→ Best for: Wealth tips, positive finance, empowerment
⚡
STYLE D
The Gold Rush
Dark charcoal/black background. Dominant gold/amber accents. Daddu on LEFT in confident pose. BIG dollar number as hero element. Thin subtitle below.
→ Best for: Income videos, salary comparisons, retirement numbers
🤫
STYLE E
The Purple Secret
Near-black with deep purple glow. White main text. Daddu in secretive pose RIGHT side. "Shh" or secret visual element on left. Mysterious atmosphere.
→ Best for: Loopholes, bank secrets, insider knowledge videos
⚖️
STYLE F
The Split Screen
Thumbnail split in half — left dark teal, right dark charcoal. VS or arrow between sides. Daddu CENTER pointing left-right. Each side has one label. No secondary text.
→ Best for: Comparison videos, X vs Y format, debate content
🔥
STYLE G
The Orange Fire
Near-black background. Warm orange/amber glow from behind Daddu. Daddu on RIGHT with frustrated/warning pose. Bold white text LEFT. Orange underline on key word.
→ Best for: "Stop doing this," contrarian warnings, habit videos
📈
STYLE H
The Minimal Dark
Pure dark background. White text ONLY. Daddu small (30%) in corner. ONE large number dominates. Clean, editorial, premium feel. No extra elements.
→ Best for: Age hook videos, "X years old" content, net worth topics
