The Complete Picture
You have 4 prompt vaults. Each vault covers a different part of making a video. This guide tells you exactly when to open each vault, which prompt to use, and in what order — from idea to uploaded video.
📌
The Golden Rule: Every video follows the same 7-phase sequence. Never skip a phase. Never run Phase 3 before Phase 2. The order matters because each phase feeds the next — your thumbnail informs your title, your title informs your script hook, your script informs your scenes.

01
Phase One — Monday Morning
Niche & Topic Research
Before any prompt is written, you need a confirmed video topic with proven demand. This phase is mostly manual research — no AI prompts needed yet. Takes 30 minutes maximum.
📂
Vault to open: Channel Bible (your channel document HTML file) → Content Master Ideas Table. This is your pre-researched topic bank. Start here before doing any new research.
1
📋
Step 1 — Check Your Content Ideas Table First
Channel Bible → Content Master Ideas Table
Manual

Open your Content Master Ideas Table (the money_frog_content_doc.html file). This table has 54 pre-researched video ideas already sorted by priority — HIGH, MED, and LOW. Start with any idea marked HIGH priority that you haven't filmed yet.

Only move to fresh research if you've exhausted all HIGH priority ideas or want to test something new based on current trends.

✅
Output from this step: One confirmed video topic with its content pillar (Real Math / Contrarian / Age Hook / List) and a rough contrarian angle already noted in the table.
2
🔍
Step 2 — YouTube Search Test
YouTube search bar → Manual analysis
Manual

Search your topic 3 different ways on YouTube. For each search look at the top 10 results and note: subscriber counts of channels that appear, view counts vs sub counts, and how recently the videos were posted.

You're looking for: videos with 100K+ views on channels under 50K subs — that's your signal that demand exceeds supply on this topic.

Also collect the top 3–5 competing video titles — you'll need these for Phase 2 and Phase 3.

📝
Write down: Topic confirmed · Pillar type · 3–5 competing titles · 1–2 top video URLs to get transcripts from · Your contrarian angle in one sentence
3
📄
Step 3 — Get Competitor Transcripts
YouTube Transcript Extension → Copy text
Manual

Go to the 1–2 top-performing competitor videos on your topic. Install the free Chrome extension "YouTube Transcript" or click ••• under the video → Show Transcript. Copy the full transcript text.

Save each transcript in a text file labeled with the video title. You'll paste these into Claude in Phase 3. Don't run any prompts yet — just collect the raw text.

✅
Phase 1 complete when you have: ① Confirmed topic ② Pillar type ③ Contrarian angle ④ 3–5 competing titles ⑤ 1–2 competitor transcripts saved as text
02
Phase Two — Monday Afternoon
Thumbnail Concept & Title
Design the thumbnail first. Write the title second. This order is critical — the thumbnail tells you what emotional register you're operating in, and the title must match that energy.
📂
Vault to open: Thumbnail Prompt Vault (thumbnail_prompt_vault.html). You will use 4 prompts from this vault in this phase. Open it now and keep it open.
1
🗓️
Prompt 1 — Check Rotation Schedule
Thumbnail Vault → Tab 6: Rotation Schedule
Manual

Open Tab 6 (Rotation Schedule) in your Thumbnail Vault. Check which style you used last week. Find the next style in the rotation. Write it down — this is your style for this video.

Why this matters: YouTube's algorithm notices when thumbnails look identical across a channel. The rotation ensures every video looks visually distinct on your channel page.

📌
Example: Last video used Style A (Red Alarm). This video uses Style B (Navy Math). Also check which Daddu pose fits your pillar type from the Pose-to-Pillar matching table on that same tab.
2
🎛️
Prompt 2 — Variation Builder
Thumbnail Vault → Tab 5: Variation Builder
Manual

Open Tab 5 (Variation Builder). Click one option in each of the 6 variable groups: Visual Style, Daddu Pose, Daddu Position, Daddu Size, Video Pillar, Text Layout.

Click "Generate Thumbnail Brief". This produces a ready-to-paste instruction block. Copy it — you'll paste it directly into the Master Thumbnail Prompt in the next step.

✅
What you get: A 6-line "Thumbnail Brief" block that tells the AI image tool exactly how to position Daddu, which style to apply, and which text layout to use.
3
🎨
Prompt 3 — Master Thumbnail Prompt
Thumbnail Vault → Tab 4: Master Prompt → AI Image Tool
Adobe Firefly / Leonardo.ai

Open Tab 4 (Master Prompt). Copy the full Master Thumbnail Generation Prompt. Fill in all [ ] fields:

  • Video topic
  • Main text for thumbnail (3–4 words max)
  • Supporting text (2–3 words)
  • Key number to highlight (if any)
  • Paste your Variation Builder brief into the Style Selection section
  • Daddu pose, position, and size from your brief

Paste the completed prompt into Adobe Firefly (first choice) or Leonardo.ai. Attach Daddu's reference image. Generate 4 variations minimum. Pick the strongest one.

⚠️
Important: The AI will NOT render text accurately. The prompt tells it to leave empty space where text goes. You add the real text in Canva using the Canva Text Finalization Prompt (also in Tab 4). Copy that second prompt and follow it in Canva after the image generates.
4
📝
Prompt 4 — Title Generation + A/B Test
Thumbnail Vault → Tab 7: Title Prompt → ChatGPT
ChatGPT (GPT-4o)

Open Tab 7 (Title Prompt). Copy the Title Generation Prompt. Fill in the fields — especially the thumbnail style selected field, because the title must match the thumbnail's emotional energy.

Paste into ChatGPT. It will generate 10 title options using all 5 proven formulas. ChatGPT is better than Claude for fast punchy title variations.

If you end up with 2–3 strong options, copy the Title A/B Test Prompt (also in Tab 7), paste your finalists into it, and run it in ChatGPT. It scores each title on 7 criteria and declares a winner.

✅
Phase 2 complete when you have: ① Finished thumbnail image (with Canva text added) ② One confirmed video title · Keep both saved — you'll need the title in Phase 3.
03
Phase Three — Tuesday
Script Writing
The most important phase. Uses 6 different prompts across two stages — competitor analysis first, then script generation. Always run transcript analysis before writing a single word of script.
📂
Vault to open: Script Prompt Vault (prompt_vault.html). You will move through tabs 1, 2, 3, 4, and 5 in this phase. Open it now.
1
✂️
Prompt 1 — Chunking Instruction (for long transcripts)
Script Vault → Tab 2: Transcript Analysis → First prompt block
Claude

Open Tab 2 (Transcript Analysis) in the Script Vault. The first prompt block is the Chunking Instruction — a short 2-line message you send to Claude before pasting any transcript.

Why you need it: If your competitor transcript is longer than 3,000 words (most 20-minute videos are 2,500–3,000+ words), Claude will start analyzing before it's seen the whole thing. The chunking instruction tells Claude to wait until you say "TRANSCRIPT COMPLETE."

📋 Chunking Instruction
Script Vault → Tab 2 → Block 1
I am going to paste a competitor transcript in parts. Do not begin analysis until I say "TRANSCRIPT COMPLETE." Just reply "Ready for next section" after each paste.

How to use it: Send this message first. Claude replies "Ready for next section." Then paste your transcript in chunks of ~2,000 words each. When done, type "TRANSCRIPT COMPLETE" — then Claude runs the full analysis.

Skip this prompt if your transcript is under 2,000 words — just paste the whole thing directly into the Transcript Analysis Prompt.

2
🔍
Prompt 2 — Transcript Analysis Prompt
Script Vault → Tab 2: Transcript Analysis → Second prompt block
Claude

Open Tab 2 (Transcript Analysis), copy the Full Transcript Analysis Prompt (the large second block). Fill in [TOPIC] at the top. Paste the competitor transcript where indicated. Run in Claude.

What this prompt does: Claude reads your competitor's video and produces 7 analysis sections:

  • Task 1: Full structural breakdown — what was the hook, where did it get weak, how did it end
  • Task 2: What they did well — specific lines and moments
  • Task 3: What they got wrong — every gap and missed opportunity
  • Task 4: The superiority plan — how your version beats theirs
  • Task 5: Extracted lines for tone inspiration (not copying)
  • Task 6: Viewer psychology map — what fear and desire the video targets
  • Task 7: Content gap keywords — topics they missed that you can cover

At the very end Claude outputs a Script Brief — a single paragraph summary. Copy this Script Brief and save it. You paste it into the Master Script Prompt in the next step.

💡
Run this for each competitor transcript. If you have 2 competitor transcripts, run this twice and save 2 Script Briefs. Both get pasted into the Master Script Prompt.
3
🎛️
Prompt 3 — Variation Builder (select your variables)
Script Vault → Tab 4: Variation Builder
Manual

Open Tab 4 (Variation Builder) in the Script Vault. Select one option from each of the 6 variable groups. This is critical for preventing pattern detection — each video must use a different combination.

The 6 variables to select:

  • Hook Type: Shocking Statistic / Bold Claim / Story Opening / Direct Question / Mid-Action
  • Narrator Tone: Discovery / Teacher / Insider
  • Math Style: Comparison Table / Timeline / Per Paycheck / Worst-Best Case
  • Pattern Interrupt: Surprising Stat / Wrong Story / Direct Question / Counter Statement
  • Closing Energy: Urgency / Empowerment / Challenge
  • Architecture: Myth Buster / Story+Math / Live Calculation / List With Twist / Debate Format

Click "Generate Variation Block". Copy the output. You'll paste this into the VIDEO BRIEF section of the Master Script Prompt.

4
📋
Prompt 4 — Master Script Prompt (Phase 1 Research)
Script Vault → Tab 1: Master Script Prompt → Run in Claude
Claude

Open Tab 1 (Master Script Prompt) — the large main prompt. This is your most important prompt. Fill in every [ ] field:

  • Topic (from Phase 1)
  • Pillar Type (from Phase 1)
  • Architecture (from Variation Builder)
  • Target Viewer age and income
  • Contrarian Angle (one sentence)
  • Competing Titles Found (paste 3–5 titles from Phase 1 research)
  • Hook Type, Narrator Tone, Math Style, Closing Energy (all from Variation Builder)
  • Opening Line (pick one from Tab 7: Opening Lines Bank)
  • Research Context (paste your Script Brief(s) from the transcript analysis here)

Paste the completed prompt into a fresh Claude conversation. Claude will run Phase 1 Research first — it presents statistics, calculations, audience pain points, and 5 hook options. Read it carefully.

⛔
Do not skip Phase 1 review. Claude will ask "Shall I proceed to the script?" — this is your chance to correct any wrong angles, inaccurate stats, or weak hooks before the script is written. Approve Phase 1 first, then Claude writes the full script.
5
🔧
Prompt 5 — Script Quality Check
Script Vault → Tab 5: Iteration Prompts → First block
Claude

After Claude outputs the full script, in the same conversation copy the Script Quality Check Prompt from Tab 5 and send it. Do not open a new chat — Claude needs to see the script it just wrote.

What this prompt does: Claude reads its own script and finds the 3 most generic sentences, any slow transitions, whether the hook would actually make someone click, any math explained in words that should have numbers, and whether the contrarian twist lands with impact.

Claude then rewrites only those weak sections — not the whole script. It shows you before and after for each change so you can approve or reject the edit.

6
👁️
Prompt 6 — Visual Cue Tag Prompt
Script Vault → Tab 5: Iteration Prompts → Second block
Claude

Still in the same Claude conversation, send the Visual Cue Tag Prompt (second block in Tab 5). This is the final step before the script goes to production.

What this prompt does: Claude reads the script and inserts [VISUAL: very specific description], [LOWER THIRD: key stat], [B-ROLL: description], and [PAUSE] tags throughout.

These tags are what you use in Phase 4 (Scene Direction) to know what image to generate for each moment. The more specific the tags, the better your scene prompts will be.

📌
Word Count Check: If the final script is under 2,400 words, also run the Word Count Fix Prompt (fourth block in Tab 5) before adding visual tags. Always check word count first.
✅
Phase 3 complete when you have: A 2,500–2,800 word script with all [VISUAL:], [PAUSE], and [LOWER THIRD:] tags inserted. Save as a text file with the video title as the filename.

Phase Four — Wednesday Morning
Scene Direction
Turn your approved script into one AI image generation prompt per 3-second scene. For a 20-minute video this produces ~400 prompts. The Master Analysis Prompt handles all of them in one run.
📂
Vault to open: Scene Prompt Generator (scene_prompt_generator.html). You will use Tab 3 (Master Analysis Prompt) primarily. Have your tagged script text file open and ready to paste.
1
📋
Prompt 1 — Master Scene Analysis Prompt
Scene Generator → Tab 3: Master Analysis Prompt
Claude

Open Tab 3 (Master Analysis Prompt) in the Scene Generator. Copy the large main prompt. Fill in:

  • Video title
  • Video pillar type
  • Total video length in minutes
  • Approximate scenes needed (video minutes × 20 = scene count)
  • Paste your full tagged script into the TRANSCRIPT section

Attach Daddu's reference image to the Claude message. Paste the completed prompt. Claude will begin outputting scene prompts in this exact format:

📋 Output Format (what Claude produces)
[SCENE 001 | 0:00–0:03] Script: "Your savings account is lying to you." Type: TYPE 1 — Daddu Presenter Daddu: YES — SHOCKED | LEFT PROMPT: Flat 2D illustration, pure white background... [SCENE 002 | 0:03–0:06] Script: "The average HYSA pays 4.8 percent right now." Type: TYPE 4 — Number/Stat Hero Daddu: NO PROMPT: Flat 2D illustration, pure white background...
💡
For long videos: Claude outputs in batches of ~50 scenes then pauses. When it stops, use the Continue Prompt (second block in Tab 3) to get the next batch. Keep going until all scenes are output.
2
➕
Prompt 2 — Continue Prompt
Scene Generator → Tab 3: Master Analysis → Second block
Claude

When Claude stops outputting mid-video, copy the Continue Prompt (second small block in Tab 3). Fill in the last scene number Claude outputted, then send it. Claude resumes from exactly where it left off.

📋 Continue Prompt
Continue from Scene {LAST SCENE NUMBER + 1}. Maintain all formatting rules. Output the next batch of scenes in the same format. One blank line between each scene block. Label this batch: "BATCH {N} (Scenes {start}–{end})"

Repeat until all scenes are generated. When done, copy all scene prompt batches into one text file. Each PROMPT field is what you feed into your image generation tool in Phase 5.

✅
Phase 4 complete when you have: All scene prompts in one text file, enter-separated, covering the full video length. Each prompt begins with "Flat 2D illustration, pure white background..."
3
⚡
Bonus — Quick Scene Generator (for manual overrides)
Scene Generator → Tab 4: Quick Scene Generator
Manual Override

Open Tab 4 (Quick Scene Generator) when you need to regenerate a single scene — for example when an AI image came out wrong and you want a slightly different prompt for that specific scene.

Paste the 3-second script words, select the scene type, pose, position, accent color, and click Generate. It builds the full prompt for that one scene instantly without running the whole analysis again.

05
Phase Five — Wednesday to Thursday
Production
Generate all images, record voiceover, assemble the video. This is the longest phase in hours but the shortest in actual decisions — the prompts have done the thinking. You're executing now.
📂
Vault to open: Scene Prompt Generator → Tab 6 (Style Rules) for image fix prompts if needed. Everything else in this phase is external tools.
1
🖼️
Step 1 — Batch Generate All Frame Images
Leonardo.ai or Adobe Firefly → Batch mode
Leonardo.ai / Firefly

Take your scene prompts text file from Phase 4. Extract only the PROMPT: field from each scene block. Paste these into Leonardo.ai's batch generation feature or run them through Adobe Firefly.

Generate all images. Download as a numbered batch matching your scene numbers. Name them: scene_001.png, scene_002.png, etc.

For scenes where Daddu appears, attach his reference image to those specific prompts in Firefly for best character consistency.

⚠️
If images come out wrong: Open Scene Generator → Tab 6 (Style Rules) → "Prompt Fix" section. It lists the 7 most common AI image errors with exact fix lines to add to your prompt. Regenerate those specific scenes only.
2
🎙️
Step 2 — Generate AI Voiceover
ElevenLabs → Your saved voice profile
ElevenLabs

Take your final script text (without the [VISUAL:] and [PAUSE] tags — just the spoken words). Paste into ElevenLabs. Use your saved voice profile for consistency across all videos.

Settings to use: Stability 55–65%, Clarity 75%, Style 40%. These produce a natural-sounding finance narrator pace — not robotic, not overly expressive.

Export as MP3. The [PAUSE] tags you added in Phase 3 tell you where to manually add silence in your audio editor — add 0.5–1 second of silence at each [PAUSE] marker.

3
🎬
Step 3 — Assemble Video
CapCut / Pictory / DaVinci Resolve
CapCut / Pictory

Import all numbered scene images into your video editor. Each image = exactly 3 seconds on the timeline. Import your ElevenLabs voiceover track and sync it with the image sequence.

Use cut transitions only — no dissolves, no fades between scenes. This matches your competitor's style exactly. Hard cuts between frames maintain the fast-paced educational feel.

Add background music at 8–12% volume — low enough to not interfere with the voice. Use royalty-free finance/corporate tracks from Pixabay or EpidemicSound.

Export at: 1920×1080, 30fps, H.264, high bitrate (8–10 Mbps minimum).

Phase Six — Friday
Upload & SEO
The final phase. One AI prompt handles the entire SEO description. Then schedule and go. Takes 30 minutes maximum if everything from previous phases is ready.
📂
Vault to open: Script Prompt Vault → Tab 6 (Full Workflow). The SEO Description Prompt is the last block on that tab.
1
📝
Prompt 1 — SEO Description Prompt
Script Vault → Tab 6: Full Workflow → Last prompt block
ChatGPT

Open Tab 6 (Full Workflow) in the Script Vault. Scroll to the bottom — the last prompt block is the SEO Description Prompt. Copy it. Fill in:

  • Video title (your confirmed title from Phase 2)
  • Main keyword (the core topic — e.g. "renting vs buying")
  • Secondary keywords (2–3 related terms — e.g. "home ownership 2026, rent or buy calculator, housing market")

Paste into ChatGPT. It outputs a complete YouTube description including opening summary, "What you'll learn" bullets, timestamps/chapters, CTAs, and 15–20 hashtags — formatted exactly for the YouTube description box.

2
📊
Step 2 — VidIQ Tags + Upload Settings
VidIQ → YouTube Studio
VidIQ

In VidIQ, search your main keyword. Copy the top 10–15 suggested tags it shows. Add these to your YouTube tags field when uploading.

Upload checklist before hitting publish:

  • Title added (from Phase 2)
  • Thumbnail uploaded (from Phase 2 — the Canva-finished version)
  • Description pasted (from SEO Description Prompt)
  • Tags added (from VidIQ)
  • Chapters added (from the timestamps in your description)
  • Category set to: Education
  • Language set to: English (United States)
  • Schedule for: Tuesday, Thursday, or Saturday at 10am EST
✅
After uploading: Check back in 60 minutes and reply to the first 3–5 comments. This engagement signal in the first hour tells YouTube's algorithm the video is active and worth pushing.
